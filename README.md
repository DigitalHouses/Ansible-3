# Ansible-3

Новый проект DigitalHouses: простая и воспроизводимая автоматизация инфраструктуры на штатном Ansible.

**Единый стандарт проекта:** [ANSIBLE_STANDARDS.md](ANSIBLE_STANDARDS.md) — v0.2 (03.11.2026).

Согласовано: запрет собственного Python без явного разрешения, проверки только для конкретного решения, практичная базовая безопасность, понимание цели до реализации, лучшие практики, отказ от необоснованных слоёв и самостоятельных архитектурных изменений.

В стандарте сохранены полезные материалы предыдущей редакции, первичные подтверждённые выводы аудита Ansible-2 и отдельно помечены предложения, которые ещё требуют согласования.

**Исключены из новой реализации:** TrueNAS, NetAlertX и прежние самостоятельные задачи №20, №30, №50 и №90. Имеющийся Ansible-2 и рабочая инфраструктура не меняются. Разработка playbooks Ansible-3 ещё не начиналась.

## Работа с Codex на CT1231

В консоли контейнера `ansible-serzhan-home`:

```bash
codex -C /opt/ansible-3
```

Дай Codex конкретную задачу на разработку или проверку. Инструкции он автоматически получает из [AGENTS.md](AGENTS.md), а настройки `.codex/config.toml` включают редактирование только рабочего проекта с запросами разрешений. Глобальное MCP-подключение `semaphore` уже настроено на CT1231, но само по себе не передаётся в обычный чат ChatGPT.

**Цикл:** изучить исходники и привязку Semaphore → изменить согласованный код → проверить → при явном задании и после штатного подтверждения запустить шаблон → получить статус, ошибки и `PLAY RECAP` → исправить при необходимости.

**Важно:** действующий Semaphore `serzhan-home` использует шаблоны существующего Ansible-2. Пока новая версия Ansible-3 не подключена к соответствующему шаблону, изменения в этом репозитории **не изменяют** работающую задачу №10. Сначала проверить привязку репозитория, затем тестировать изменения.

Подробнее: [docs/autonomous-development.md](docs/autonomous-development.md).
