# Ansible-3

Новый проект DigitalHouses: простая и воспроизводимая автоматизация инфраструктуры на штатном Ansible.

**Единый стандарт проекта:** [ANSIBLE_STANDARDS.md](ANSIBLE_STANDARDS.md) — v0.3 (11.11.2026).

**S24: фиксированы последние октеты HOME/CORE и VM/CT ID.**
Сеть /24 берётся из сети каждого объекта, а не из общего стандарта.
HOME Media — **.223 / VM2223**, CORE Media — **.243 / VM2243**.
192.168.11.0/24 относится только к дому владельца; клиенты используют
свои подсети. Полная таблица — в S24. Legacy VM не меняются автоматически.

Согласовано: запрет собственного Python без явного разрешения, проверки только для конкретного решения, практичная базовая безопасность, понимание цели до реализации, лучшие практики, отказ от необоснованных слоёв и самостоятельных архитектурных изменений.

В стандарте сохранены полезные материалы предыдущей редакции, первичные подтверждённые выводы аудита Ansible-2 и отдельно помечены предложения, которые ещё требуют согласования.

**Исключены из новой реализации:** TrueNAS, NetAlertX и прежние самостоятельные задачи №20, №30, №50 и №90. Действующий Ansible-2 и рабочая инфраструктура не изменены. В Ansible-3 создан и успешно испытан минимальный smoke-playbook; продуктивные роли и задачи ещё не перенесены.

## Работа с Codex на центральном DEV

Разработка ведётся в CT1254 (`192.168.11.254`) через ChatGPT/Desktop Commander и установленный Codex CLI:

```bash
codex -C /home/dev/work/ansible-3
```

Инструкции — [AGENTS.md](AGENTS.md); переносимая `.codex/config.toml` не предполагает, что на каждой машине установлен Semaphore MCP. После штатного enrollment доступ к Semaphore из DEV обеспечивается через HTTPS API с отдельным токеном `dev-automation` и проверкой TLS по [bootstrap/README.md](bootstrap/README.md). Не копируйте токен в чат или репозиторий.

**Цикл:** изучить исходники и привязку Semaphore → изменить согласованный код → проверить → при явном задании и после штатного подтверждения запустить шаблон → получить статус, ошибки и `PLAY RECAP` → исправить при необходимости.

Исторический интерактивный Codex/MCP в CT1231 описан в [docs/development-environment.md](docs/development-environment.md); он не заменяет центральный DEV.

**Важно:** в проекте Semaphore `serzhan-home` оба источника существуют параллельно: старый `dh_ansible` (repository ID 1, template №10 ID 5) и новый `Ansible-3` (repository ID 4, inventory ID 2, smoke-template ID 15). Новый шаблон уже проверен запуском **№23: success**, `localhost ok=1 changed=0 failed=0`. Изменения Ansible-3 **не влияют** на старую задачу №10. Перед функциональным тестом всегда проверять связь шаблона с правильным репозиторием.

**Фактическое окружение и восстановление:** [docs/development-environment.md](docs/development-environment.md) — версии, пути, настройки Codex/MCP, разрешения, проверенные объекты Semaphore, smoke-test и runbook для чистого CT1231.
