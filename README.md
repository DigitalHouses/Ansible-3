# Ansible-3

Новый проект DigitalHouses. Сначала утверждаем правила разработки, затем проводим аудит Ansible-2 и только после этого реализуем инфраструктуру.

**Стандарт проекта:** [ANSIBLE_STANDARDS.md](ANSIBLE_STANDARDS.md) — редакция v0.1, рабочий документ для обсуждения.

В v0.1 зафиксированы уже согласованные принципы: отказ от собственного Python без отдельного разрешения, проверки только ради конкретного решения и минимально достаточная безопасность. Остальные пункты помечены как предложения до отдельного согласования.
