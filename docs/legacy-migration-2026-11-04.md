## Границы

- Legacy — исторический экземпляр для чтения/аудита; **не** запускать Semaphore и его прежние расписания без отдельного решения.
- Исходный CT1231 и архив пока сохраняются; CTID 1231 **занят**, несмотря на `stopped`.
- Продуктивные задачи, парольные файлы, расписания, старые site-данные и секреты не переносились вручную между хостами.
- Исключение `.199` из DHCP-пула/резервация на маршрутизаторе **не подтверждены**; проверить отдельно.
- Отзыв регистрации устройства `ansible-serzhan-home` на портале Desktop Commander **не подтверждён**; локальное удаление программы не выполняет отзыв регистрации.
- Тест полного восстановления Legacy после новой аварии, доступ к его Semaphore и тест всех прежних задач **не проводились**.

## Где выполняется разработка

- Все новые изменения Ansible-3 — **из центрального DEV CT1254**, с отдельным Git-репозиторием `DigitalHouses/Ansible-3`.
